## Recommended subject

Aegis — durable state and concurrency infrastructure for long-running agentic workflows

## Message

Hello Neo team,

I'm Andrzej Mikulski, an independent builder working on Aegis, a systems layer for long-running agentic workflows.

The core idea is deliberately narrow: make workflow state durable, concurrent mutations explicit, recovery reproducible, and execution history inspectable. The current public repository contains an executable reference implementation, correctness tests, a canonical failure/recovery demo, CI, and a reproducible benchmark protocol.

I am not claiming production scale or product-market fit yet. The purpose of the project is to test a specific systems hypothesis with code and adversarial workloads: whether developers building persistent multi-agent workflows will prefer a dedicated state/concurrency primitive to rebuilding persistence and recovery inside application code.

I built the repository to make that hypothesis easy to inspect and falsify:

I would be glad to discuss whether Aegis is a fit for Neo's current or next founder/residency path.
