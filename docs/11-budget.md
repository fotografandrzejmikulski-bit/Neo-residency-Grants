# Grant Budget — $40,000

The original research draft proposed a detailed $40K allocation. This repository replaces it with an evidence-first operating budget because actual residency logistics, taxes, hardware needs, and legal costs depend on the founder's circumstances.

| Category | Planning cap | Principle |
|---|---:|---|
| Living / local operating costs | $14,000 | Protect build time; use only necessary expenses. |
| Development hardware | $6,000 | Buy only equipment that materially improves iteration or testing. |
| Security / external review | $7,000 | Threat modeling, penetration testing, or specialist review after MVP scope stabilizes. |
| Legal / incorporation reserve | $4,000 | Use only when company formation is justified by evidence. |
| Software / APIs / services | $4,000 | Prefer residency partner credits where suitable. |
| Travel / contingency | $5,000 | Buffer for unplanned operating needs not covered by the program. |
| **Total** | **$40,000** | |

## Budget rule

Do not spend grant capital to manufacture vanity metrics. Infrastructure credits should be used for reproducible benchmarks and real development workloads, not for creating artificial scale claims.

## Infrastructure-credit rule

The $100K+ partner benefits are treated as non-cash infrastructure capacity, not as cash funding. Any credit allocation should be recorded separately from the grant budget.
